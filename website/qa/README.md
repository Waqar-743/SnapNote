The vector update is verified in Chromium through Playwright. [Results](v1.4.1-results.json), [desktop](v1.4.1-desktop.png) and [mobile](v1.4.1-mobile.png) captures cover sample-clip search, text/image filters, copy to the actual browser clipboard, quick-access show/hide, mobile navigation, FAQ disclosure, valid anchors, bitmap removal except The Mentor, reduced motion and layouts from 320 to 1440 CSS pixels.

A simulated future release verifies that MSI, EXE, checksums and the displayed version update without editing the page. Screenshot version labels use the simulated release, not a shipped application version.

The site has no browser-testing runtime dependency. Earlier result files and captures describe previous designs and remain as historical evidence.
