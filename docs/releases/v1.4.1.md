# SnapNote v1.4.1

- Alt+X now hides the focused quick-access window on a second press and reopens it on the next. From another app or a minimized window, it brings quick access forward. Holding the keys does not repeatedly toggle the window.
- Images pasted into notes have an explicit Delete image button. Removal preserves surrounding text and can be undone independently of a recent paste or OCR action.
- Image clip cards have a visible trash button with confirmation. Deletion is saved to the workspace; independent copies embedded in notes remain in their notes.
- Settings includes About SnapNote with version 1.4.1 and developer Waqar Ahmed.
- Website downloads follow the latest GitHub release. MSI, EXE and checksum links resolve automatically, with a latest-release page fallback when the API is unavailable.
- The website keeps The Mentor wolf and replaces the other bitmap assets with SVG icons, animated illustrations and an interactive sample-clip preview. Reduced-motion preferences are respected.

Windows 10/11, x64. Install using the MSI or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier.
