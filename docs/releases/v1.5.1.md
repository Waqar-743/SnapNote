# SnapNote v1.5.1

- Replaced the favicon and app icon with the new glossy SnapNote icons selected by the owner: the dark glossy icon is now the desktop app icon (window, taskbar, installer, and Windows Store logos), and the light pencil icon pairs with it for light contexts.
- The app and website favicons are theme-aware: light scheme shows the light pencil icon, dark scheme shows the dark glossy icon. An Apple touch icon was added to the website.
- The in-app sidebar brand now uses the new icons, matched to the active theme.
- The README icon section uses the light pencil icon by default and the dark glossy icon in dark mode; the superseded root logo images were removed.
- The website header and footer brand marks now use the new icons with the same theme-aware switching.

Windows 10/11, x64. Install using the MSI or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier.
