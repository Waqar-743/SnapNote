# SnapNote v1.7.0

### Unified Custom Title Bar & Window Controls
- Replaced the native OS window title bar (`decorations: false`) with a single unified custom title bar integrated directly into the top navigation bar.
- Added custom **Minimize**, **Maximize / Restore**, and **Close** controls aligned flush to the top-right corner with theme-matched hover/active states and a standard destructive red hover state on Close.
- Empty space in the top bar acts as a smooth drag region; double-clicking toggles maximize/restore while keeping all header buttons clickable and excluded from dragging.
- Preserved reliable 8-direction window edge and corner resizing when windowed, and added a minimal draggable title bar with window controls on locked and loading screens.
- Added a 1-click **Keep on top** pin button in the top bar (synced with Settings) so users can float SnapNote above other apps anytime.
- Quick Access (`Alt + X`) now cleanly unmaximizes before shrinking and restores the maximized window state when returning to the full workspace.

### Brand & Visual Design Refresh
- Upgraded the **SnapNote** wordmark beside the app icon to a signature two-tone treatment (**Snap** in black on light / crisp white on dark, **Note** in warm golden yellow matching the icon) and kept it visible at the top of the window across full, medium, and compact `560×640` Quick Access widths.
- Replaced all native browser popups (`window.prompt`, `window.confirm`, `window.alert`) with a custom, theme-matched SnapNote modal dialog system (`AppDialog`) for adding/renaming/removing folders & sessions, deleting clips & notes, filling snippet `{{variables}}`, workspace encryption, and clearing history.
- Removed the empty-state capture button across all sections and introduced a warm layered golden-terracotta gradient canvas in both light and dark modes.
- Added 1-click **Settings & privacy** access in the top header, instant green checkmark feedback when copying a clip, `Escape` to clear focused search, smoother card hover states, and refined typography legibility.

### Faster Clip Management
- Added a direct **Delete** button beside Copy on every **text, link, snippet, and image** clip card (grouped neatly on the right side of each card footer).
- Added a **Delete selected** bulk action in the multi-select bar so multiple clips can be removed in one step.

### Product Website & Documentation
- Redesigned the SnapNote product website from scratch with upgraded typography (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`), light/dark site theme toggle, interactive Light/Dark/Quick Access showcase tabs, cloud-app comparison table, full SEO + JSON-LD structured data (`SoftwareApplication`, `HowTo`, `FAQPage`), and bidirectional backlinks.
- Updated all website download buttons to always redirect to GitHub's latest release page instead of initiating direct binary downloads from the site.
- Refreshed `README.md` to document all v1.7.0 features and links.

---

Windows 10/11, x64. Install using the MSI (recommended) or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned, so Windows SmartScreen may ask for confirmation on first install. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier (`come.codespace.snapnote`).
