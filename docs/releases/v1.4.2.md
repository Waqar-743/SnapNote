# SnapNote v1.4.2

- Fixed the startup error reported in [#9](https://github.com/Waqar-743/SnapNote/issues/9): on machines without the Microsoft Visual C++ Redistributable, `snapnote.exe` failed with "The code execution cannot proceed because VCRUNTIME140.dll was not found." The Windows build now statically links the C runtime, so the installers are fully self-contained and run on any Windows 10/11 machine out of the box.
- The build pipeline verifies every release binary and fails the workflow if it still imports any Visual C++ runtime DLL.
- The product website was redesigned around real application screenshots: a professional layout, relevant content, and complete SEO (canonical URL, Open Graph and Twitter cards, structured data, sitemap and robots.txt). The interactive mock preview and the mascot illustration were removed from the public site.

Windows 10/11, x64. Install using the MSI or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier.
