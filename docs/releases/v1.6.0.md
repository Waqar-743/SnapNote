# SnapNote v1.6.0

- The workspace header brand at the top left is now a full identity: the glossy SnapNote icon sits beside the app name, so the name and the icon are both present in the header.
- The header brand is doubled in size — the wordmark grows from 15px to 30px and the icon renders at 44px, making the top-left header a clear brand anchor instead of small, easily missed text.
- The folders drawer brand grows with it (48px icon, 26px name), so both brand spots belong to the same visual family.
- Both brand marks stay theme-aware (dark glossy icon on the light theme, light pencil icon on the dark theme) and sit directly on the system surface colour — no separate background is introduced, so the header never clashes with the active light or dark design.
- The wordmark hides on narrow quick-access windows exactly as before; the icon keeps the brand present there.

Windows 10/11, x64. Install using the MSI or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier.
