# SnapNote v1.5.0

- Fixed the dashboard issues reported in [#10](https://github.com/Waqar-743/SnapNote/issues/10) and [#11](https://github.com/Waqar-743/SnapNote/issues/11): the logo image was removed from the top menu and the remaining title, divider, and rail icons were realigned.
- Added a proper first-run starter screen that walks through the working of SnapNote — clipboard history, `Alt + X` quick access, organizing with favorites, folders, tags, sessions and snippets, the notes editor with image tools and OCR, and local privacy. It has a skip button at the top left and a centered continue button at the end, never occupies more than 30% of the window, and only appears the first time the app is opened.
- Settings & privacy now links the [GitHub project](https://github.com/Waqar-743/SnapNote) (source, docs, and releases) and opens it in the system default browser.
- The favicon and every bundled app icon (ICO, ICNS, PNG sizes, and the Windows Store logos) are regenerated from the dashboard logo; unused template assets were removed.
- Performance: clip search and view filtering, selection lookups, and sidebar group counts are memoized; clip dates share one `Intl.DateTimeFormat`; the sidebar brand logos were downscaled to display size, cutting about 1 MB from the shipped assets.
- The native Windows validation suite now completes the starter walkthrough through its own buttons and asserts the 30% screen bound.

Windows 10/11, x64. Install using the MSI or setup EXE below. SHA-256 checksums are provided alongside the installers. Builds are unsigned. OCR requires a separately installed Tesseract engine. Existing notes and workspace storage keep the same application identifier.
