Selected by the owner: **A — The Mentor**, 2026-10-15.

Each concept includes front, side, three-quarter, teaching, standing, and explaining views. The concepts were generated with the built-in image generation tool, inspected, and saved in this repository. They are concept illustrations rather than vector logos or an animation rig.

Keep A's snow-white fur, upright ears, cheek ruff, bushy tail, dark glasses, charcoal suit, white shirt, restrained tie, and wooden pointer consistent in subsequent illustrations. Use adult proportions, a calm smile, open gestures, and a helpful teaching posture. Avoid intimidating teeth, childish proportions, busy costumes, or changing glasses and suit between views.

Use the wolf for product guidance and selected website sections. Keep everyday desktop controls clear and functional. A production cutout or individual pose should be generated from the selected model sheet as a reference, rather than recreating the character from memory.

The owner confirmed that the website will be new and built on a separate branch **after the desktop implementation and validation**. No website work has started yet.
